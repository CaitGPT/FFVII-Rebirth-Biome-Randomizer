# Runtime

What ships in the release, and how the pieces fit. The design is in [HOW-IT-WORKS](../docs/HOW-IT-WORKS.md); building is in
[BUILDING](BUILDING.md).

| Path | What it is |
| --- | --- |
| `Native/src/main.cpp` | The UE4SS C++ mod: loader check, table fingerprints, guarded batch writes (`BiomeRandomizerSetMany`), spawn-level watch, state file I/O |
| `Native/src/spawn_points.hpp` | Fills a camp's empty spawn-size lists from the nearest size that has points |
| `Native/src/persistent_dispatch.hpp` | Calls the Lua tick on the game thread every 100 ms; stops at quit. `BIOME_DIAG` builds add timing counters |
| `Native/src/write_arguments.hpp` | Reads write arguments off the Lua stack (LuaMadeSimple getters consume them) |
| `Native/src/reviewed_layout.hpp` | Generated by `tools/world_layout.py`: per-table sizes, offsets and fingerprints |
| `Scripts/main.lua` | Entry point; says so in the log when the native part is missing or inactive |
| `Scripts/automatic.lua` | The selector: compositions, fights, counters, unlocks |
| `Scripts/lifecycle.lua` | The seeded selection function |
| `Scripts/state_store.lua` | The state file: seed, counters, unlocked fiends |
| `Scripts/world_pools.lua` | Generated: camps, pools, count ranges, unlocks and their story flags |
| `Scripts/biome_json.lua` | rxi's json.lua (MIT) |
| `Scripts/config.lua` | `enabled` and `seed` |
| `tests/` | Offline Lua 5.4 cases (`python -m pytest runtime/tests`, needs `lupa`) |
| `Native/tests/` | The compiled argument-reader regression |

Log lines start with `[BiomeRandomizerRuntime]`. The events are JSON: `selector_ready`, `table_ready`, `level_left`,
`fight_observed`, `cycle_committed`, `assignment_unlocked`, `state_write_failed` and `automatic_disabled`.
